# T-0001 최종 보고: 버거쌓기(stack-burger) 기획

## 결론
- 기획 완료함. 상세 내용은 `shared/P-0001/analysis.md` 참고할 것.
- 순수 HTML/CSS/JS 3파일(index.html, style.css, game.js)로 빌드 없이 구현 가능함.
- 조이님이 미정 사항 6건을 확정하고 개발을 승인하시면 개발 착수함.

## 핵심 결과
| 항목 | 내용 |
|---|---|
| 화면 | 메인(시작, 조작법, 최고 점수) → 게임(시간·점수 / 문제·트레이 / 하단 9칸 + 제출) → 결과(점수, 성공·오답 수, 다시하기) |
| 하단 1행 | 아랫빵, 양상추, 고기, 치즈, 토마토, 윗빵, 감자튀김, 치킨너겟, 콜라 (가정). 커서는 좌우로만 이동함 |
| 키 조작 | ←→ 이동, Space 선택, Backspace 되돌리기, Esc 전체 비우기, Enter 제출. 마우스로도 같은 동작 가능함 |
| 문제 생성 | 빈 주문 없음. 속재료 1~4개(중복 허용). 사이드 0~3개(중복 없음) |
| 판정 | 햄버거는 쌓는 순서까지 일치해야 정답. 사이드는 종류만 일치하면 됨. 오답이면 감점 없이 같은 문제 재도전 |
| 점수 | 정답 1건당 (재료 수 + 사이드 수) x 10점. 최고 점수는 localStorage에 저장함 |
| 그림 | `assets/freeBuns.png` 스프라이트 시트를 잘라서 사용함 |

## 조이님 확인 필요 사항
1. 속재료 최대 개수를 4개로 해도 될지
2. 오답일 때 감점이나 시간 차감을 넣을지
3. 같은 사이드 메뉴를 여러 개 시키는 주문(예: 콜라 2잔)을 허용할지
4. 숫자키 1~9로 칸을 바로 고르는 단축키를 넣을지
5. 효과음을 넣을지
6. 콤보 보너스나 점점 어려워지는 요소를 넣을지

# T-0002 최종 보고: 버거쌓기 게임 구현

## 결론
- 구현과 테스트를 마침. 테스트 통과, 결함 0건 (`shared/P-0001/test-report-T-0002.md`)
- `stack-burger/index.html` 을 브라우저로 열면 바로 플레이 가능함
- 새로 만든 파일: `index.html`, `style.css`, `game.js`. 원본 `assets/freeBuns.png` 는 그대로 둠 (`shared/P-0001/dev-changes-T-0002.md`)

## 핵심 결과
| 항목 | 결과 |
|---|---|
| 판정 | 윗빵을 올릴 때 비교해서 틀리면 햄버거만 초기화함. 감점 없음. 다 맞으면 자동으로 다음 문제로 넘어감 |
| 모드 | 이지(위치 고정, 속재료 1~3개), 하드(문제마다 9칸 섞임, 속재료 3~6개, 커서 1열로 돌아감) |
| 콤보 | 콤보 2부터 (콤보-1) x 10점 추가, 최대 50점 |
| 기록 | 닉네임(없으면 '아무개')별 점수를 localStorage에 저장, 모드별 상위 10건 표시 |
| 색감 | CSS filter로 밝게 보정함. 보정 이미지는 만들지 않음 |
| 효과음 | Web Audio로 구현, 새 에셋 없음 |

## 조이님 확인 필요 사항
1. 메인 화면 연출과 효과음은 테스트 환경(헤드리스)에서 확인하지 못함. 브라우저에서 직접 확인이 필요함
2. 토마토가 필터 때문에 주황빛이 강함. 채도를 낮출지 결정이 필요함
3. 점수는 빵을 빼고 속재료와 사이드만 셈(`(속재료 수 + 사이드 수) x 10`). 기획서의 '햄버거 재료 수'를 빵까지 포함하는 뜻으로 볼지 결정이 필요함
