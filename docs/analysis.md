# T-0001/T-0002 버거쌓기(stack-burger) 기획

## 결론
- 1분 동안 주문(햄버거 0~1개 + 사이드 0~4개)을 최대한 많이 완성하는 단일 페이지 웹 게임으로 만듦.
- 이지/하드 2개 모드, 콤보 보너스, 닉네임별 점수 기록, Web Audio 효과음을 넣음.
- 순수 HTML/CSS/JS, 빌드 없이 `index.html` 을 열면 바로 실행되는 구성으로 함.

## 목표와 완료 기준
- 게임 목표: 60초 안에 메뉴를 최대한 많이 완성하는 것
- 메인(닉네임, 모드 선택) -> 게임(60초) -> 결과 -> 다시하기 흐름이 끊김 없이 동작함.
- 커서 이동은 키보드 좌우 키로 하고, 마우스로 칸을 클릭하면 커서도 그 칸으로 옮겨짐. 재료 선택은 키보드(Space)나 마우스 클릭 둘 다 가능함.
- 문제 생성, 판정, 콤보, 점수, 기록 저장이 아래 규칙대로 동작함.

## 1. 화면 구성
| 화면 | 구성 요소 |
|---|---|
| 메인 | 게임 제목, 큰 햄버거 연출, 닉네임 입력, 모드 선택(이지/하드), 게임 시작(Enter 또는 클릭), 기록 보기, 소리 켜기/끄기, 조작법 안내 |
| 게임 | 상단: 남은 시간(60초), 점수, 완성 수, 콤보 / 가운데: 문제(햄버거 쌓인 모습 + 사이드) / 가운데 아래: 내가 만든 트레이 / 그 아래: 비우기 띠 / 맨 아래: 재료+사이드 10칸 1행 |
| 결과 | 완성 메뉴 수(가장 크게), 점수, 최대 콤보, 이번 기록 순위, 다시하기(Enter), 메인으로(Esc) |
| 기록 | 모드 탭(이지/하드), 순위표 (6항 참고) |

- 아래 1행 기본 순서 [가정]: 아랫빵, 양상추, 고기, 치즈, 토마토, 윗빵, 감자튀김, 치킨너겟, 콜라, 치킨윙 (10칸)
- 1행뿐이므로 커서는 좌우로만 이동함. 시작 커서는 1열
- 주문과 내 트레이 공통 배치: 세로로 반 나눠 왼쪽 가운데에 햄버거, 오른쪽 2x2 칸에 사이드를 위에서부터 채움
  - 주문 영역: 트레이 이미지 없이 흰 배경
  - 내 트레이: `freeBuns.png` 맨 아래 트레이 이미지를 배경으로 씀. 햄버거 크기와 관계없이 트레이 크기 고정
  - 햄버거와 사이드는 각자 영역을 거의 채우는 크기로 그림. 햄버거 재료는 간격 없이 붙여 쌓음
  - 사이드는 최대 4개로 2x2 칸을 모두 채울 수 있음 (최대 4개는 조이님 확인 중)
- 비우기 띠: 내 트레이와 아래 재료 칸 사이의 가로 띠 영역. 클릭하면 트레이를 전부 비움 (트레이 위 비우기 버튼은 없앰)
- 버튼: 테두리와 그림자 없이 표시
- 메인 햄버거 연출: 스프라이트를 크게 확대(화면 높이 40% 정도). 아랫빵부터 재료가 층 사이를 띄운 채 하나씩 내려옴. 윗빵까지 쌓이면 간격이 줄며 살짝 합쳐지고 잠깐 멈춘 뒤 반복함. 재료가 떠 있을 때 재료 사이 간격을 좁게 함
- 이미지: `stack-burger/assets/freeBuns.png` (288x272 픽셀아트 스프라이트 시트). 1행에 햄버거·빵·양상추·고기·치즈·토마토, 2~3행에 감자튀김·너겟·콜라, 그 아래에 치킨윙으로 보이는 그림이 있음 [추정]. 칸 좌표는 개발 시 확인 필요

## 2. 조작 키
| 동작 | 키보드 | 마우스 |
|---|---|---|
| 커서 이동 | ←, → (양 끝에서 반대편으로 순환) | 재료/사이드를 클릭하면 커서도 그 칸으로 이동 |
| 선택 | Space | 재료/사이드 클릭 |
| 전체 비우기 | Esc | 비우기 띠 클릭 |

- 되돌리기(Backspace)와 숫자키 단축키는 넣지 않음
- 제출 키 없음. 완성 판정이 자동으로 됨 (4항 참고) [가정]
- 재료 선택: 트레이 맨 위에 1개 쌓음. 쌓는 순서 제한 없음
- 사이드 선택: 넣기/빼기 토글 (같은 사이드는 1개만 담김)

## 3. 문제 생성 규칙
| 항목 | 이지 | 하드 |
|---|---|---|
| 햄버거·사이드 둘 다 없음 | 허용 안 함 (다시 뽑음) | 같음 |
| 햄버거 구성 | 아랫빵 + 속재료 + 윗빵 고정 | 같음 |
| 속재료 개수 | 1~3개 [가정] | 3~6개 [가정] |
| 속재료 중복 | 허용 (예: 고기 2장) | 같음 |
| 사이드 개수 | 0~4개 (최대 4개는 확인 중), 같은 사이드 중복 없음 (확정) | 같음 |
| 하단 10칸 위치 | 고정 | 새 문제가 나올 때마다 랜덤으로 섞음 |

- 하드에서 위치가 바뀌면 커서는 1열로 돌아감. 이지는 커서 위치 유지
- 직전 문제와 완전히 같은 문제는 다시 뽑음

## 4. 판정, 콤보, 점수
- 틀린 걸 중간에 알려주지 않음. 감점 없음. 단, 아래 두 경우는 바로 초기화함
  - 첫 재료가 아랫빵이 아님: 그 재료를 올리는 순간 초기화 (사이드 선택은 해당 없음)
  - 재료가 8개(빵 2개 + 속재료 6개)를 넘음: 9번째 재료를 올리는 순간 초기화
- 햄버거 판정: 윗빵을 올리는 순간 아래에서 위로 쌓은 순서를 문제와 비교함
  - 같음: 햄버거 완성 표시
  - 다름: 쌓은 햄버거만 초기화하고 같은 문제 계속함 (사이드는 유지)
- 위 초기화는 모두 사이드는 그대로 두고 햄버거만 비움
- 주문 완성: 햄버거 완성(햄버거 없는 주문은 생략) + 담은 사이드 종류가 문제와 같아지는 순간 자동 완성 [가정]
  - 완성 연출: 점수가 오르기 직전에 타이머를 약 0.5초 멈추고 재료가 떨어져 합쳐지는 모션을 보여줌. 연출 중에는 입력을 막음
  - 연출이 끝나면 점수를 올리고 다음 문제로 넘어감
- 기본 점수: 주문 1건당 `(햄버거 재료 수 + 사이드 수) x 10점`
- 콤보 조건: 햄버거 초기화 없이 연속으로 완성한 주문 수. 햄버거가 한 번이라도 초기화되면 콤보 0
- 콤보 보너스: 콤보 2부터 주문 1건마다 `(콤보 - 1) x 10점` 추가, 최대 50점(콤보 6 이상) [가정]
- 60초 종료 시 만들던 트레이는 무시하고 결과 화면으로 이동

## 5. 효과음 (Web Audio)
- 새 에셋 없이 Web Audio API(OscillatorNode)로 브라우저에서 바로 소리를 만들 수 있음. 보류 불필요
- 브라우저 자동재생 정책 때문에 첫 키 입력이나 클릭(게임 시작) 뒤에 소리를 켜야 함

| 상황 | 소리 |
|---|---|
| 커서 이동 | 아주 짧은 틱 |
| 재료 쌓기/사이드 담기 | 짧은 퐁 |
| 햄버거 초기화 | 낮은 부저 |
| 주문 완성 | 올라가는 2음 |
| 콤보 | 완성음보다 높은 음 |
| 남은 10초 | 1초마다 틱 |
| 게임 종료 | 짧은 종료음 |

## 6. 점수 기록
- 저장: localStorage (키 예: `stackBurger.records`). 서버 없음
- 닉네임: 게임 시작 전 입력, 앞뒤 공백 제거, 최대 10자 [가정]. 비어 있으면 '아무개'
- 저장 항목: 닉네임, 모드, 점수, 완성 메뉴 수, 최대 콤보, 날짜·시간
- 표시: 모드별 점수 높은 순 상위 10건. 점수가 같으면 완성 메뉴 수가 많은 순 [가정]
- 모드별 상위 10건만 남기고 나머지는 지움

## 7. 에셋 색감 보정
| 방식 | 장점 | 단점 |
|---|---|---|
| 이미지 파일 직접 보정 | 어느 브라우저든 똑같이 보임 | 원본이 바뀜, 수치를 바꿀 때마다 다시 작업해야 함 |
| CSS `filter` (권장) | 원본 보존, `brightness`·`saturate` 수치만 바꾸면 바로 조정 | 브라우저에서 계산하는 비용이 조금 듦 (이 정도 규모면 영향 없음) |

- 결정: CSS `filter: brightness(1.2) saturate(1.2)` 정도로 시작해서 화면 보며 조정함
- 배경도 밝은 색(예: 연한 크림색)으로 해서 전체 분위기를 밝게 맞춤

## 8. 권장 기술 구성
- 순수 HTML/CSS/JS, 외부 라이브러리·빌드 도구 없음
- 파일: `index.html`, `style.css`, `game.js`, `assets/freeBuns.png`
- 화면 전환은 한 페이지 안에서 영역 표시/숨김으로 처리
- 그림은 스프라이트 시트를 CSS `background-position` 으로 잘라 씀, 픽셀아트라 `image-rendering: pixelated` 적용

## 확정 사항
- 같은 사이드 여러 개 주문(예: 콜라 2잔) 허용 여부: 허용 안 함으로 확정함 (조이님 답변)

## 미정 사항
- 사이드 최대 개수 4개 (치킨윙 추가로 4종, 2x2 칸을 모두 채움): 조이님 확인 중. 확인 전까지 4개로 작성함

## 제외 범위
- 서버, 회원, 온라인 랭킹, 모바일 터치 전용 조작, 되돌리기, 숫자키 단축키
